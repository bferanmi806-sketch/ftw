In the Home Assistant app, clicking the version now opens a dialog that names the running version and says Home Assistant installs updates and rollbacks for the app. Before, the click did nothing. A Docker install that FTW cannot update says the same and tells you to update it the way you installed it. On these installs the header also shows the connection light and the optimizer warning again; both were hidden along with the update check.
